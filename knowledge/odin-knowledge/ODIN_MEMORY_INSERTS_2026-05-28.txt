KEY: saas_pricing_5_strategies
VALUE: Five SaaS pricing strategies that can double revenue without new features: (1) Van Westendorp survey — reveals willingness-to-pay, price sensitivity, and which features customers value most by rank order. Run this before finalizing tiers. (2) Histogram feature analysis — database query showing % of customers using each feature; move enterprise-only features to top tier, make mid-use features paid add-ons. (5) Upsells/cross-sells ("sawdust monetization") — partner with adjacent vendors, keep 30-50% on referral with zero delivery cost.
