WHAT IS ODIN
━━━━━━━━━━━━
ODIN is a fully custom business operations hub built for Brock Shue (Shue Box LLC),
a Memphis TN real estate wholesaling company. It is a Flask/PostgreSQL web application
hosted on Railway.app. ODIN connects GoHighLevel (called "XLeads"), Slack, Discord,
and the Anthropic Claude API into a unified command center operated primarily through
Slack DMs.

LIVE URL: https://odin-api-production-e85d.up.railway.app

MCTP SCORING FRAMEWORK
━━━━━━━━━━━━━━━━━━━━━━
MCTP = Motivation + Condition + Timeline + Price (0-10 total)
  Motivation  0-3  (why are they selling?)
  Condition   0-2  (property condition)
  Timeline    0-3  (how urgently do they need to sell?)
  Price       0-2  (are they realistic on price?)

Hot  = 8-10  — Route to approval queue, alert Brock immediately
Warm = 5-7   — Alert Brock, route to acquisition manager
Cold = 0-4   — Log and follow up later
